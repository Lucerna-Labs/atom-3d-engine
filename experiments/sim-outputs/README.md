# Simulation Output Archive

This folder preserves raw and near-raw outputs from local, Arc/XPU, Rust, Kaggle, TPU, GPU, RF, renderer, and cross-domain primitive simulations.

Publication rule: terminal scrollback is not evidence. Every run that may matter later should leave a timestamped artifact here or be imported here with a checksum.

## Folder Layout

- `runs/` - timestamped logs captured from commands run through `../capture-sim-output.ps1`.
- `runs/*.command.ps1` - generated command wrappers for captured runs.
- `runs/*.stdout.txt` and `runs/*.stderr.txt` - separate stdout/stderr sidecars for captured runs.
- `imported/` - older output files copied in from their original experiment folders.
- `manifest.tsv` - command-captured run manifest generated by the capture script.
- `existing-output-inventory.tsv` - checksum inventory of imported or already-existing output files.
- `archive-file-inventory.tsv` - checksum inventory for every other file currently in this archive folder.

## Capture A New Run

From the repo root:

```powershell
.\experiments\capture-sim-output.ps1 `
  -Name rf-crypto-self-repair-arc-xpu `
  -Category rf-transport `
  -WorkingDirectory "C:\Projects\3D Primitve math engine" `
  -- & "C:\Projects\discovery-search-12h-gpu\.venv-arc\Scripts\python.exe" `
    "experiments\rf-crypto-arc\rf_crypto_self_repair.py" --trials 32768 --k 48 --m 28 --extra 24
```

The log records:

- local and UTC timestamps
- working directory
- exact command
- git HEAD and short dirty status
- machine and user
- raw stdout/stderr
- process exit code
- SHA256 checksum

## Retention Rules

- Keep successful runs.
- Keep failed runs if they informed a decision.
- Do not hand-edit raw logs. Add interpretation in a separate `RUN_NOTES.md` or report.
- Preserve seeds, trial counts, hardware/runtime, and command line arguments.
- If a result came from Kaggle, TPU, or a remote notebook, export the notebook output or downloaded run artifact into `imported/` and record the source URL or notebook slug in the notes.
- If an output is too large for normal git tracking later, keep the manifest and move the raw artifact to the release package or Kaggle dataset. Do not silently discard it.

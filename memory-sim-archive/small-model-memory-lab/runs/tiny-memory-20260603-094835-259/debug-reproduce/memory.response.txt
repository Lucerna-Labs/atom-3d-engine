

1. Reproduce Before Repair: Start with a minimal reproducible case. If the crash is intermittent, use a staging environment or a controlled test run to isolate the trigger.

2. One Variable Moved: Isolate the variable that changed after the deploy. If multiple variables changed, reset and move one at a time to identify the culprit.

3. The Confidence Label Saved the Answer: Label confidence based on evidence strength. High confidence for direct logs, medium for inferred patterns, low for orientation only.

4. The Next Action Had an Owner: Define the next action and assign ownership. Write the verb, owner, and evidence needed to confirm the fix.

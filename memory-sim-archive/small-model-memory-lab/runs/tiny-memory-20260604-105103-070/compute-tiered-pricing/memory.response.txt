The utility bill charges $0.12 per unit for the first 100 units and $0.18 per unit for any units above 100, plus a fixed fee of $6.  
For 135 units, the first 100 units cost:  
$0.12 × 100 = $12.  

The remaining units are:  
135 − 100 = 35 units.  
These cost:  
$0.18 × 35 = $6.30.  

Total variable cost:  
$12 + $6.30 = $18.30.  

Add the fixed fee:  
$18.30 + $6 = $24.30.  

Final answer: **$24.30**

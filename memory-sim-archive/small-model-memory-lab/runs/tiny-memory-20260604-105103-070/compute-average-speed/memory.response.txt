**Step‑by‑step solution**

1. **First leg (150 km)**  
   - Speed = 60 km/h  
   - Time₁ = Distance ÷ Speed = 150 km ÷ 60 km/h = **2.5 h**  

2. **Second leg (90 km)**  
   - Speed = 45 km/h  
   - Time₂ = 90 km ÷ 45 km/h = **2 h**  

3. **Total distance and total time**  
   - Total distance = 150 km + 90 km = **240 km**  
   - Total time = 2.5 h + 2 h = **4.5 h**  

4. **Average speed (total distance ÷ total time)**  
   - Average speed = 240 km ÷ 4.5 h ≈ **53.33 km/h**  

---

**Visible answer:** The average speed for the whole trip is **≈ 53.33 km/h**.

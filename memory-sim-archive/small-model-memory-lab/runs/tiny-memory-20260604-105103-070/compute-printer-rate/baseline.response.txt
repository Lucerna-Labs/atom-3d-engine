**Setup:**  
- Four printers produce 480 pages in 6 minutes → rate = \( \frac{480\text{ pages}}{6\text{ min}} = 80\text{ pages/min} \) per printer.  
- Three printers need to make 720 pages at the same rate: time = \( \frac{720\text{ pages}}{3 \times 80\text{ pages/min}} = \frac{720}{240}\text{ min} = 3\text{ min}. \)

**Answer:**  
Three printers need **3 minutes**.

**Setup:**  
Let \( P \) be the number of pages printed by one printer per minute.  

From the given:  
4 printers → 480 pages in 6 minutes  
So, for 1 printer: \( P = \frac{480}{4 \times 6} = \frac{480}{24} = 20 \) pages/minute.

Now, we want to find the time \( t \) (in minutes) that 3 printers need to print 720 pages:  
\( 3 \times P \times t = 720 \)  
Substitute \( P = 20 \):  
\( 3 \times 20 \times t = 720 \) → \( 60t = 720 \) → \( t = \frac{720}{60} = 12 \) minutes.

**Final answer:**  
The 3 identical printers need **12 minutes**.

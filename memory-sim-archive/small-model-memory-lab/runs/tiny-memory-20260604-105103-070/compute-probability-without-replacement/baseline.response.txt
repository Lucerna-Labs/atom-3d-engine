The total number of balls is 8 (5 red + 3 blue).  
The probability that the first ball drawn is red is 5/8.  

After removing one red ball, there are 7 balls left, with 4 red remaining.  
The probability that the second ball drawn is also red is therefore 4/7.  

Multiplying these probabilities gives:

\[
\frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14}.
\]

The total number of balls is \(5 + 3 = 8\).  
When two balls are drawn without replacement, the probability that the first ball is red and the second is also red is  

\[
P(\text{first red}) \times P(\text{second red} \mid \text{first red}) = \frac{5}{8} \times \frac{4}{7}.
\]

Multiplying gives  

\[
\frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14}.
\]

The final numeric answer with the full unit name is **\( \frac{5}{14} \)**.

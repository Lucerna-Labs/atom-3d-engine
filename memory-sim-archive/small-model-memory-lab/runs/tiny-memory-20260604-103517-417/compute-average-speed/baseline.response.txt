**Distance:**  
- Leg 1: 150 km at 60 km/h → Time = Distance / Speed = 150 / 60 = **2.5 hours**.  
- Leg 2: 90 km at 45 km/h → Time = 90 / 45 = **2 hours**.  

**Total distance:** 150 + 90 = **240 km**.  
**Total time:** 2.5 + 2 = **4.5 hours**.  

**Average speed:** Total distance / Total time = 240 / 4.5 ≈ **53.3 km/h**.

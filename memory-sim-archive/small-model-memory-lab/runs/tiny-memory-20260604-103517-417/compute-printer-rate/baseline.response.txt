**Setup:**  
Rate of one printer = \( \frac{480\text{ pages}}{6\text{ min} \times 4\text{ printers}} = 20\text{ pages/min} \).  

For 3 printers, rate = \( 3 \times 20 = 60\text{ pages/min} \).  
Time to make 720 pages = \( \frac{720\text{ pages}}{60\text{ pages/min}} = 12\text{ min} \).  

**Uncertainty:**  
Assumes identical printers and constant speed; real-world factors (e.g., paper jams) could affect accuracy.

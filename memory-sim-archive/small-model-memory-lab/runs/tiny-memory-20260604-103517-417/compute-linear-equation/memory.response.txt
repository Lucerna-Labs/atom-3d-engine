**Task:** Solve for x: 3(x - 4) + 2x = 46. Show the algebra briefly.

**Solution:**  
Expand: 3x - 12 + 2x = 46 → Combine like terms: 5x - 12 = 46 → Add 12 to both sides: 5x = 58 → Divide by 5: x = 58/5.

**Answer:**  
x = 58/5 (or 11.6).

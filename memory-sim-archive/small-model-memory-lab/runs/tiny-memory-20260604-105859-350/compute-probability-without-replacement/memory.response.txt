**Probability Calculation:**  
- Total balls = 5 + 3 = 8  
- Probability first ball is red = 5/8  
- After one red ball drawn, remaining balls = 4 red + 3 blue = 7 total  
- Probability second ball is red given first was red = 4/7  
- Combined probability (without replacement) = (5/8) × (4/7)  

**Simplified Decimal:**  
(5 ÷ 8) × (4 ÷ 7) = (0.625) × (0.5714...) ≈ **0.3571**  

**Final Answer:**  
The probability both balls are red is approximately **0.3571**.

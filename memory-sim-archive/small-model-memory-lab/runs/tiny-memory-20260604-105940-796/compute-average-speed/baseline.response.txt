**Distance:**  
150 km + 90 km = **240 km**  

**Time for first part:**  
Time₁ = Distance / Speed = 150 km ÷ 60 km/h = **2.5 hours**  

**Time for second part:**  
Time₂ = Distance / Speed = 90 km ÷ 45 km/h = **2 hours**  

**Total time:**  
Total Time = Time₁ + Time₂ = 2.5 h + 2 h = **4.5 hours**  

**Average speed:**  
Average Speed = Total Distance / Total Time = 240 km ÷ 4.5 h ≈ **53.33 km/h**

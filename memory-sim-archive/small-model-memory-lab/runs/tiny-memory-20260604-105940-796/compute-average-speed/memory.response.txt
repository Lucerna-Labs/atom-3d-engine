**Distance:**  
150 km + 90 km = **240 km**  

**Time for first leg:**  
time₁ = distance / speed = 150 km ÷ 60 km/h = **2.5 h**  

**Time for second leg:**  
time₂ = 90 km ÷ 45 km/h = **2 h**  

**Total time:**  
total_time = 2.5 h + 2 h = **4.5 h**  

**Average speed:**  
average_speed = total_distance / total_time = 240 km ÷ 4.5 h ≈ **53.33 km/h**

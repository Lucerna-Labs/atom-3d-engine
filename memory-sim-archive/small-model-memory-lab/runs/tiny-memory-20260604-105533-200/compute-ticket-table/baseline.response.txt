Team A starts with 12 open tickets, closes 7, so it has **5** remaining (12 - 7 = 5). Team B starts with 20 open tickets, closes 13, so it has **7** remaining (20 - 13 = 7).

Team A has more open tickets. The total number of open tickets is the sum of the remaining tickets from both teams: 5 + 7 = **12**.

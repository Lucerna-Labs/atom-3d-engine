**Task:** Solve for x: 3(x - 4) + 2x = 46. Show the algebra briefly.

**Solution:**  
1. Expand: 3x - 12 + 2x = 46 → 5x - 12 = 46  
2. Add 12 to both sides: 5x = 58  
3. Divide by 5: x = 58/5  

**Uncertainty:** The problem is straightforward, but ensure no arithmetic errors in expansion or division.

**Setup:**  
- Each printer makes 480 pages in 6 minutes → rate = 480/6 = **80 pages/min**.  
- For 3 printers, total rate = 3 × 80 = **240 pages/min**.  

**Calculation:**  
Time needed for 720 pages at 240 pages/min:  
\[
\text{Time} = \frac{720}{240} = 3 \text{ minutes}.
\]

**Answer:**  
3 printers need **3 minutes**.

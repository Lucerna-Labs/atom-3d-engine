**Setup:**  
Rate of one printer = \( \frac{480\text{ pages}}{6\text{ min}} = 80\text{ pages/min} \).  

For 3 printers, rate = \( 3 \times 80 = 240\text{ pages/min} \).  
Time to make 720 pages = \( \frac{720}{240} = 3\text{ min} \).

**Uncertainty:**  
Assumes identical printers and no downtime; real-world factors (e.g., paper jams) may affect accuracy.

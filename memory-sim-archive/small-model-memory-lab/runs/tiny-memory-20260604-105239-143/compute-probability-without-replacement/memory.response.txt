- Probability of independent events = P(A) × P(B).  

**Task Analysis:**  
1. **Total balls:** 5 red + 3 blue = 8 balls.  
2. **First draw (red):** P(red₁) = 5/8.  
3. **Second draw (without replacement, still red):** After removing one red ball, 7 balls remain with 4 red → P(red₂ | red₁) = 4/7.  
4. **Combined probability:** P(both red) = (5/8) × (4/7).  

**Calculation:**  
(5/8) × (4/7) = (20)/(56) = 5/14 ≈ 0.3571.

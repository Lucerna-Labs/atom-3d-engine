The utility bill charges $0.12 per unit for the first 100 units, then $0.18 per unit for any additional units above 100. The fixed fee is $6. For 135 units, there are 35 units in excess of 100.

Calculation:
- Cost for first 100 units: 100 × $0.12 = $12.00
- Cost for additional 35 units: 35 × $0.18 = $6.30
- Total variable cost: $12.00 + $6.30 = $18.30
- Add fixed fee: $18.30 + $6.00 = $24.30

Final answer: **$24.30**

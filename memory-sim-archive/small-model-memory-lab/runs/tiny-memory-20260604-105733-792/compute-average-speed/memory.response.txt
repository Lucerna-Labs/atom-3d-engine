**Recalled experience:**  
Average speed = total distance ÷ total time  

**Task facts:**  
- Distance₁ = 150 km at 60 km/h → Time₁ = 150 ÷ 60 = 2.5 h  
- Distance₂ = 90 km at 45 km/h → Time₂ = 90 ÷ 45 = 2 h  

**Calculation:**  
Total distance = 150 + 90 = 240 km  
Total time = 2.5 + 2 = 4.5 h  
Average speed = 240 ÷ 4.5 = 53.33… ≈ **53.3 km/h**  

**Answer:** The average speed for the whole trip is **53.3 km/h**.

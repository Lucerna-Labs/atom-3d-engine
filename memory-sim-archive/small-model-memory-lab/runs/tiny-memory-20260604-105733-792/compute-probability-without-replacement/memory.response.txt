The recalled experience is that when drawing two balls **without replacement** from a set of 8 balls (5 red, 3 blue), the probability that both are red is calculated by multiplying the probabilities at each draw.

First draw:  
Probability first ball is red = \( \frac{5}{8} \).

Second draw (after one red has been removed):  
Remaining balls = 7 total, with 4 red left.  
Probability second ball is red = \( \frac{4}{7} \).

Multiplication:  
\( \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14} \).

Final answer in plain text with unit name:  
The probability is \( \frac{5}{14} \) (approximately 35.7%).

**Recalled experience:**  
The task is to calculate the number of units available after a series of operations starting from an initial stock. The calculation method uses simple arithmetic, following the given sequence of actions without repeating any memory.

---

**Step-by-step calculation:**  

1. **Initial stock:** 150 units  
2. **Sold in 4 days at 18 units per day:**  
   \( 18 \times 4 = 72 \) units sold  
3. **After sales, remaining stock:**  
   \( 150 - 72 = 78 \) units  
4. **Received additional units:** +65 units  
   \( 78 + 65 = 143 \) units  
5. **Reserved for a client:** −20 units  
   \( 143 - 20 = 123 \) units  

---

**Final answer:**  
The number of units available is **123**.

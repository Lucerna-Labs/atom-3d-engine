**Setup:**  
- Four printers produce 480 pages in 6 minutes → rate = \( \frac{480\text{ pages}}{6\text{ min}} = 80\text{ pages/min} \) per printer.  
- Three printers need to make 720 pages at the same rate.

**Calculation:**  
Pages needed: 720  
Rate per printer: 80 pages/min  
Time for three printers: \( \frac{720\text{ pages}}{3 \times 80\text{ pages/min}} = \frac{720}{240} = 3\text{ min} \)

**Answer:**  
3 minutes

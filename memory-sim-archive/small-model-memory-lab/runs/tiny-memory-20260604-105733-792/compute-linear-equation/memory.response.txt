**Recalled experience:**  
The task is to solve a linear equation by expanding and combining like terms, then isolating \(x\).  

**Calculation steps:**  
1. Expand the left side:  
   \[
   3(x - 4) + 2x = 3x - 12 + 2x
   \]  
2. Combine like terms:  
   \[
   (3x + 2x) - 12 = 5x - 12
   \]  
3. Set equal to the right side and solve for \(x\):  
   \[
   5x - 12 = 46
   \]  
4. Add 12 to both sides:  
   \[
   5x = 58
   \]  
5. Divide by 5:  
   \[
   x = \frac{58}{5} = 11.6
   \]  

**Final answer:**  
\(x = 11.6\)

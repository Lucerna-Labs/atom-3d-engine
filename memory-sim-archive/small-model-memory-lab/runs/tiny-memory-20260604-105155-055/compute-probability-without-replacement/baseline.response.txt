The probability both balls are red is calculated by multiplying the probabilities of drawing a red ball first, then another red ball without replacement.

First draw:  
P(red) = 5 / (5 + 3) = 5/8  

Second draw (without replacement):  
P(second red | first red) = 4 / (5 + 2) = 4/7  

Multiply the probabilities:  
(5/8) × (4/7) = 20/56 = 5/14  

Final answer: 5/14


- Ask: What exactly must be decided, and what would change the decision?
- Map: Write a one-line map: Question → Decision → Unknowns → Evidence that could flip the decision.
- Verify: For the first source, check source, date, conditions, and provenance; if any are weak, downgrade confidence and flag.
- Open: For each unknown term, add a one-line glossary entry, a one-line mechanism, a trusted source, and a failure mode.
- Check: Ask an expert or a trusted source to validate the glossary and mechanism.

Why this works:
- It forces you to separate what you must decide from what you don't know yet.
- It prevents over-trusting a single confident source by checking provenance and conditions.
- It builds a thin, testable model of the domain so you can spot contradictions early.

- Keep the map on a single line or a small table.

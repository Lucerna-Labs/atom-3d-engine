Let's break down the problem step by step.

Step 1: Determine the number of units charged at each rate.
- The first 100 units are charged at $0.12 per unit.
- Units above 100 (in this case, 35) are charged at $0.18 per unit.

Step 2: Calculate the cost for the first 100 units.
Cost = Number of units * Rate
= 100 units * $0.12/unit
= $12

Step 3: Calculate the cost for the remaining units.
Number of additional units = Total units - First 100 units
= 135 units - 100 units
= 35 units

Cost = Number of additional units * Rate
= 35 units * $0.18/unit

Distance traveled = (150 + 90) km
Time taken to travel first part of journey = Distance / Speed = 150/60 h
Time taken to travel second part of journey = Distance / Speed = 90/45 h

Total time taken = Time taken in first part + Time taken in second part = 2.5 + 2 h = 4.5 h

Average speed = Total distance travelled / Total time taken = (150+90)/4.5 km/h = 53.33 km/h

**Task:**  
A job starts at 9:15 AM. Phase 1 takes 45 minutes, phase 2 takes 70 minutes, then there is a 10-minute break, and phase 3 takes 35 minutes. What time does it finish?  

**Answer:**  
The total duration is 45 + 70 + 10 + 35 = 160 minutes. Adding this to the start time (9:15 AM) gives a finish time of **10:25 AM**.

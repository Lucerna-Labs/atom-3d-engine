   - **Action:** Reproduce the crash in a staging environment.

2. **Isolate the Variable**
   - **Action:** Move one variable to test its effect.
   - **Uncertainty:** If multiple variables move together, success can be as useless as failure.
   - **Next Action:** Reset and move one variable to see if the crash persists.

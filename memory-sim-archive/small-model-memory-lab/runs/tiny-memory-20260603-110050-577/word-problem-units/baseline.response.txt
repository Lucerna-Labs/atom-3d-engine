We are given: "A pump fills 3 tanks in 12 minutes. Each tank has the same size. How many minutes should 5 identical pumps need to fill 10 identical tanks? Show the setup briefly and include units."

Interpretation: One pump fills 3 tanks in 12 minutes. So the rate of one pump is: (3 tanks) / (12 minutes) = 0.25 tanks per minute. Alternatively, we can think in terms of tank-minutes: To fill 3 tanks, one pump takes 12 minutes, so the work required is 3 tanks. The pump's rate is 3/12 = 1/4 tank per minute.

Now we have 5 identical pumps. Their combined rate is 5 * (1/4) = 5/4 tanks per minute

**Analysis:**  
The utility bill has three components:  
- Base unit rate: $0.12 per unit for up to 100 units.  
- Extra unit rate: $0.18 per unit for units above 100.  
- Fixed fee: $6.

- Cost for base units: 100 × $0.12 = $12.00  
- Cost for extra units: 35 × $0.18 = $6.30

**Distance:**  
- First leg: 150 km  
- Second leg: 90 km  

**Time for each leg:**  
- Time₁ = Distance / Speed = 150 km ÷ 60 km/h = **2.5 hours**  
- Time₂ = 90 km ÷ 45 km/h = **2 hours**  

**Total distance and total time:**  
- Total distance = 150 km + 90 km = **240 km**  
- Total time = 2.5 h + 2 h = **4.5 hours**  

**Average speed (plain arithmetic):**  
Average speed = Total distance ÷ Total time = 240 km ÷ 4.5 h ≈ **53.33 km/h**

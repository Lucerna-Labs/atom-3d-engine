**Setup:**  
- Rate per printer = 480 pages / (6 min × 1 printer) = **80 pages/min**.  
- For 3 printers, total rate = 3 × 80 = **240 pages/min**.  

**Calculation:**  
Time needed for 720 pages at 240 pages/min:  
\[
\text{Time} = \frac{720 \text{ pages}}{240 \text{ pages/min}} = 3 \text{ minutes}.
\]

**Answer:** **3 minutes**.

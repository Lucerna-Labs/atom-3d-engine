Setup: The cost of electricity can be calculated using the formula Cost = (Number of Units * Rate) + Fixed Fee.
Arithmetic: Number of Units = 135
Rate = $0.12 per unit for the first 100 units, $0.18 per unit for units above 100
Fixed Fee = $6

Cost = (135 - 100) * $0.18 + ($0.12 * 100) + $6
= 35 * $0.18 + $12 + $6
= $6.30 + $12 + $6
= $24.30

Final Answer: The bill for 135 units would be $24.30.

Setup: The cost of electricity can be calculated using the formula Cost = (Number of Units * Rate) + Fixed Fee.
Arithmetic: Number of Units = 135
Rate for first 100 units = $0.12/unit
Rate for units above 100 = $0.18/unit
Fixed Fee = $6

Cost = (135 - 100) * $0.18 + ($0.12 * 100) + $6
= 35 * $0.18 + $12 + $6
= $6.30 + $12 + $6
= $24.30

Final Answer: The total bill for 135 units is $24.30.

The setup is: (Number of printers) * (Time taken by one printer) = Total time for all printers.
So, we have 4 printers making 480 pages in 6 minutes. We can set up the equation as follows:

(4 printers) * (x minutes per printer) = 6 minutes

Now, let's solve for x:

4x = 6
x = 6 / 4
x = 1.5 minutes per printer

This means that each printer takes 1.5 minutes to print a page.

Next, we want to find out how long it will take for 3 printers to print 720 pages. Using our previous calculation, we know that each printer takes 1.5 minutes to print a page. Therefore, three printers working together would take half the time because they are printing at double the rate.

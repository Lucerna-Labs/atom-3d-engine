The probability of drawing two red balls without replacement from a bag containing 5 red and 3 blue balls is calculated as follows:  
First, draw one red ball (probability = 5/8). Then, draw another red ball given the first was red (probability = 4/7). Multiply these probabilities: (5/8) × (4/7) = 20/56.  

Final answer: 20/56 ≈ 0.3571 (or 35.71%).

**Memory Pattern:** Relevant remembered experiences, compressed into cognitive cues.  
**Task:** A warehouse starts with 150 units. It sells 18 units per day for 4 days, receives 65 units, then reserves 20 units for a client. How many units are available? Show the arithmetic.  

**Calculation:**  
- Initial: 150 units  
- Sold (4 × 18): 72 units  
- Received: +65 units  
- Reserved: -20 units  
- Available = 150 − 72 + 65 − 20 = **123 units**  

**Answer:** 123 units.

task=arithmetic
I remember the tile calculation failure. The room was 12 by 9 feet, so area was 108 square feet. Each tile was 1.5 by 1.5 feet, so each tile covered 2.25 square feet. 108 divided by 2.25 was 48. Ten percent extra made 52.8, and rounding up made 53. The passing answer returned only 53 when the prompt asked for only the number.
